SCRAPING CASE

Stockholm Weather Scraper

A web scraping project that collects the upcoming week's weather forecast for Stockholm.

See this week's weather ↓

THE IDEA

Turning website data into structured information.

In this project I use Node.js and Cheerio to scrape weather information from Klart.se.

The scraper collects information about the upcoming week in Stockholm, including maximum temperature, minimum temperature, precipitation and wind.

The information is then saved as structured JSON data and displayed visually here in my portfolio.

PROCESS

How it works

01

Fetch

Node.js downloads the HTML from the Stockholm weather page on Klart.se.

02

Scrape

Cheerio reads the HTML and finds the information that belongs to each day.

03

Structure

The information is converted into structured JavaScript objects containing the weather data.

04

Save

The first seven days of the forecast are saved in a JSON file.

05

Display

The website reads the JSON file and creates the weather cards shown above.

WHAT I LEARNED

From HTML to useful data.

Through this project I learned how web scraping works in practice. I learned how to fetch a webpage, inspect its HTML, extract specific information with Cheerio and turn that information into structured JSON data.

I also learned how scraped data can be connected to a frontend and presented visually instead of only being shown in the terminal.
